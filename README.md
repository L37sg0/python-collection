# Python & Django Projects Collection

A comprehensive index and overview of Python scripts, desktop GUI utilities, automation tools, and full-stack web applications developed across various learning phases, professional projects, and personal workflows.

---

## Repository Overview & Inventory

---

### 🖥️ Desktop Utilities & Automation

* **`calculator/`**
    * **Description:** Classic desktop calculator built with Python's **Tkinter** and `ttk` widgets, featuring a custom state machine, event routing, and an MS Paint UI mockup.
    * **Tech Stack:** Python 3, Tkinter, `functools.partial`.


* **`key-robot/`**
    * **Description:** Keyboard automation and macro tool created during night-shift technical support to automate DHCP server reboots and prevent network dropouts during traffic peaks.
    * **Tech Stack:** Python 3, Tkinter, `pynput`, PyInstaller.


* **`web-scrapper/`**
    * **Description:** Dual-mode (GUI & CLI) web scraper based on Fabrizio Romano's *Learning Python*, using **BeautifulSoup** to extract and save embedded web images as files or base64 JSON archives.
    * **Tech Stack:** Python 3, Tkinter, `requests`, `BeautifulSoup` (`bs4`).



---

### 🌐 Enterprise & Integration Tools

* **`vtenext-translator/`**
    * **Description:** Specialized Python package and utility developed while working at a wind park to automate and streamline localized language pack generation for **vtenext CRM**.
    * **Tech Stack:** Python 3, Google Translator API, Setuptools, JSON chunking and multi-volume dictionaries.



---

### ⚙️ Full-Stack & Web Framework Projects

* **`python-recall/`**
    * **Description:** Compilation of core Python fundamentals, data structures, OOP concepts, utility scripts, and third-party API integrations (GitLab REST API, OpenPyXL spreadsheet automation).
    * **Tech Stack:** Python 3, Requests, OpenPyXL.


* **`django-polls/`**
    * **Description:** Reusable Django web application built following the official Django tutorial for conducting online polls, packaged as an installable Python module via `setuptools`.
    * **Tech Stack:** Python, Django, SQLite.


* **`mysite/`**
    * **Description:** Foundational Django project container managing global settings, root URL routing, and custom-branded admin panel templates (`base_site.html`).
    * **Tech Stack:** Python, Django, SQLite.


* **`django-wind-manager/`**
    * **Description:** Enterprise management dashboard adapted from a maritime fleet tracking template, tailored for wind turbine operations, meteorology tracking, and maintenance scheduling.
    * **Tech Stack:** Python, Django, SB Admin 2, Bootstrap, Chart.js.


* **`django-questions-app/`**
    * **Description:** Full-stack quiz and question management application pairing a modular Django REST API backend with a standalone Bootstrap-powered frontend client.
    * **Tech Stack:** Python, Django REST Framework, Bootstrap 5, Heroku deployment configs.


* **`django-react/`**
    * **Description:** Full-stack web application integrating a Django REST Framework backend with a ReactJS single-page application frontend featuring built-in user authentication.
    * **Tech Stack:** Python, Django REST Framework, ReactJS.


* **`django-ember/`**
    * **Description:** Full-stack library management application pairing a Django REST API backend with an Ember.js reactive frontend, built from the FreeCodeCamp *ELI5 Full-Stack Basics* tutorial.
    * **Tech Stack:** Python, Django, Ember.js, SQLite.
